# Dulce Barro

Catálogo web con Node.js, Express y Microsoft SQL Server.

## Ejecución

1. Ejecutar base_datos.sql en SQL Server Management Studio.
2. Ajustar la variable conexion en servidor.js al servidor local.
3. Instalar las dependencias:

   npm install

4. Iniciar el servidor:

   npm start

5. Abrir http://localhost:3000.

La conexión utiliza autenticación de Windows y requiere el
controlador ODBC indicado en servidor.js.
